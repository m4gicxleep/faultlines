## Included PDFs

### Linux From Scratch 11.2

- File: [linux-from-scratch-11.2.pdf](books/linux-from-scratch-11.2.pdf)
- Created by Gerard Beekmans; managing editor Bruce Dubbs. Copyright 1999–2022 Gerard Beekmans.
- Source: `livros/LFS-BOOK-11.2.pdf` in the collection above.
- Original project: https://www.linuxfromscratch.org/lfs/
- License: [CC BY-NC-SA 2.0](https://creativecommons.org/licenses/by-nc-sa/2.0/); computer instructions may be extracted under the MIT license. Full notices remain in Appendix F.
- Selected for studying toolchains, building a Linux system, filesystem layout and boot configuration.
- This is the September 2022 edition, preserved as a study reference. Consult the original project for current releases and security advisories before building a system.

### GNU/Linux Command-Line Tools Summary

- File: [gnu-linux-command-line-tools-summary.pdf](books/gnu-linux-command-line-tools-summary.pdf)
- Author: Gareth Anderson. Conversion and index work: Chris Karakas. Copyright 2003–2006 Gareth Anderson.
- Source: `livros/GNU-Linux-Tools-Summary.pdf` in the collection above.
- Original publication and online text: https://tldp.org/LDP/GNU-Linux-Tools-Summary/html/
- License: GNU Free Documentation License 1.1 or later, with no invariant sections or front/back-cover texts. The complete license is included in the PDF.
- Selected for shell usage, file operations, text processing and system inspection.
- This is revision 1.2 from 2006. Some commands, service-management examples and options are dated; check local manual pages before use.

### Python e Orientação a Objetos

- File: [python-orientacao-a-objetos-caelum.pdf](books/python-orientacao-a-objetos-caelum.pdf)
- Author/publisher: Caelum.
- Source: `apostilas/apostila-python-orientacao-a-objetos.pdf` in the collection above.
- Original source and license declaration: https://github.com/caelum/apostila-python-orientacao-a-objetos
- License: [CC BY-NC-ND 4.0](https://creativecommons.org/licenses/by-nc-nd/4.0/).
- Selected for programming fundamentals, data structures, functions, file handling and object orientation. Useful background for writing analysis and lab automation scripts.
- Preserved unchanged. IDE screenshots and version-specific setup instructions may be dated.
